# 商品价格监控（price_monitor）

一个 config 驱动的商品价格监控小工具：定时抓取商品页面，用正则提取当前价格，
记入 CSV 做历史存档；发现降价自动提醒，价格跌破你设的阈值时输出醒目告警。

只用 Python 标准库（`urllib` / `re` / `csv` / `argparse`），无第三方依赖，开箱即跑。

## 功能

- **配置驱动**：所有监控目标写在 `config.json` 里，加商品只改配置不动代码
- **多页面格式兼容**：正则带一个捕获组即可提取价格，`¥1,599.00` / `329元` / `data-price` 属性等写法都支持
- **历史存档**：每次结果追加到 `prices.csv`（列：时间,商品,价格），UTF-8-SIG 编码，Excel 直接打开不乱码
- **智能对比**：与该商品上次记录对比，输出 `[基线]` / `[降价]` / `[涨价]` / `[持平]`
- **阈值告警**：价格跌破 `threshold` 时打印醒目告警行
- **容错**：单个商品抓取失败、正则未命中、正则写错都不中断整体流程，失败项单独报错并继续；有失败项时退出码为 1，方便接入定时任务告警

## 运行方法

```bash
# 默认读取当前目录的 config.json
python3 price_monitor.py

# 指定配置文件（prices.csv 会落在配置文件所在目录）
python3 price_monitor.py --config /path/to/config.json
```

建议用 cron / 计划任务定时执行，例如每天上午 9 点跑一次：

```bash
0 9 * * * cd /path/to/01-price-monitor && python3 price_monitor.py >> monitor.log 2>&1
```

## 配置说明（config.json）

```json
{
  "targets": [
    {
      "name": "星云声学 X3 无线降噪耳机",
      "url": "https://example.com/item/12345",
      "pattern": "<span class=\"price\">¥([0-9,.]+)</span>",
      "threshold": 799.0
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 商品名，用于 CSV 记录和输出展示 |
| `url` | 是 | 商品页地址，支持 `http(s)://` 和 `file://` |
| `pattern` | 是 | 提取价格的正则表达式，**必须带一个捕获组**，组内为价格数字 |
| `threshold` | 否 | 告警阈值；当前价格低于它时输出告警。不填则只做降价提醒 |

## 输入输出示例

输入：`config.json`（见上）。输出分两部分：

**1. 控制台输出**（实时提醒）：

```
[基线] 星云声学 X3 无线降噪耳机: 首次记录 ¥899.00
[降价] 星云声学 X3 无线降噪耳机: ¥899.00 → ¥749.00（降了 ¥150.00）
  ※※※ 告警：已跌破阈值 ¥799.00，当前 ¥749.00 ※※※
[持平] 极光轴 K87 三模机械键盘: 当前 ¥329.00
[失败] 某商品: 页面抓取失败（URLError: ...），已跳过
```

**2. `prices.csv`**（历史存档）：

```csv
时间,商品,价格
2026-10-09 13:12:16,星云声学 X3 无线降噪耳机,899.00
2026-10-09 13:12:21,星云声学 X3 无线降噪耳机,749.00
```

## 运行演示

以下为本机（Python 3.12.3）真实运行记录。演示用 `demo/` 目录下 3 个虚构商品页面，
`config.json` 中的 url 指向它们的 `file://` 路径。

**第一次运行——建立基线：**

```
$ python3 price_monitor.py
开始检查 3 个商品（2026-10-09 13:12）
--------------------------------------------------
[基线] 星云声学 X3 无线降噪耳机: 首次记录 ¥899.00
[基线] 极光轴 K87 三模机械键盘: 首次记录 ¥329.00
[基线] 远望 27 英寸 4K 显示器: 首次记录 ¥1599.00
--------------------------------------------------
完成：成功 3/3，记录已写入 .../01-price-monitor/prices.csv
```

**把耳机价格从 ¥899 改到 ¥749 后，第二次运行——降价 + 跌破阈值告警：**

```
$ python3 price_monitor.py
开始检查 3 个商品（2026-10-09 13:12）
--------------------------------------------------
[降价] 星云声学 X3 无线降噪耳机: ¥899.00 → ¥749.00（降了 ¥150.00）
  ※※※ 告警：已跌破阈值 ¥799.00，当前 ¥749.00 ※※※
[持平] 极光轴 K87 三模机械键盘: 当前 ¥329.00
[持平] 远望 27 英寸 4K 显示器: 当前 ¥1599.00
--------------------------------------------------
完成：成功 3/3，记录已写入 .../01-price-monitor/prices.csv
```

**容错演示**（页面不存在 / 正则未命中 / 正则写错，各自独立报错、互不影响）：

```
$ python3 price_monitor.py --config /tmp/bad_config.json
开始检查 3 个商品（2026-10-09 13:12）
--------------------------------------------------
[失败] 不存在的页面: 页面抓取失败（URLError: <urlopen error [Errno 2] No such file or directory: '/tmp/no-such-file.html'>），已跳过
[失败] 正则不命中: 页面中未匹配到价格（pattern 未命中），已跳过
[失败] 坏正则: 正则表达式无效（unterminated character set at position 1），已跳过
--------------------------------------------------
完成：成功 0/3，记录已写入 /tmp/prices.csv
```
